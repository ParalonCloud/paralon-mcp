# Security

## Reporting a vulnerability

Please email **contact@paraloncloud.com** with what you found and how to reproduce it. Do not
open a public issue for a vulnerability. We answer within two business days.

## What this package can do

`@paraloncloud/mcp` runs on your machine with your ParalonCloud API key. With the `rental` scope
it can start rentals and spend credits; with the `nodes` scope it can change your own nodes. Give
it a key with only the scopes you need, and keep your MCP client's confirmation of tool calls on.

## Where it comes from

Every release since 1.6.0 is published from this repository's `publish` workflow with npm
provenance: the npm page links the commit and the workflow run that built it.
